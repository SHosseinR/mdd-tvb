# Atlas coordinates

`Schaefer2018_200Parcels_7Networks_centroids.csv` was downloaded without
modification from the CBIG Schaefer2018 release:

https://raw.githubusercontent.com/ThomasYeoLab/CBIG/master/stable_projects/brain_parcellation/Schaefer2018_LocalGlobal/Parcellations/MNI/Centroid_coordinates/Schaefer2018_200Parcels_7Networks_order_FSLMNI152_2mm.Centroid_RAS.csv

The simulation records the file's SHA-256 digest in every run metadata file.
These are MNI parcel centroids, not cortical-surface dipole positions; radial
orientations derived from them are a template approximation for the current
single-sphere EEG monitor.
